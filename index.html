      Instellingen

      Laat op 0 staan, dan gebruikt hij automatisch jouw account.

      Alleen gebruikt zolang er nog weinig loopdata is. Daarna rekent de coach met wat je echt gelopen hebt.

      Kies tempo alleen als je in intervals.icu een drempeltempo voor Run hebt ingesteld.

      Zo koppel je alles

      1. Maak een gratis account op intervals.icu.
      2. Ga naar Settings, koppel Garmin Connect en vink Upload planned workouts aan.
      3. Zet in Garmin Connect je maximale hartslag goed (of laat je horloge die meten).
      4. In intervals.icu: Settings, helemaal onderaan bij Developer Settings, maak een API key en plak die hierboven.
      5. Druk op Test verbinding, zet Demo-modus uit en sla op.

      Je API key blijft alleen op deze telefoon bewaard. Deel hem met niemand.
