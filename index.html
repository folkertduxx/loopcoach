    Instellingen

    Laat op 0 staan voor je eigen account.

    Hiermee worden je tempozones nauwkeuriger. Leeg laten: de app schat ze uit je runs.

    Loop je sneller of langzamer dan deze marge, dan piept en trilt je horloge.

    Koppelen

    1. Maak een gratis account op intervals.icu.
    2. Koppel bij Settings je Garmin Connect en zet Upload planned workouts aan.
    3. Maak onderaan Settings bij Developer Settings een API key en plak die hierboven.
    4. Test verbinding, zet demo uit en sla op.

    Je API key blijft alleen op deze telefoon.
